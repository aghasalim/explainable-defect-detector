# Runtime deps for the deployed demo (Streamlit Community Cloud / Docker).
#
# The +cpu pin plus the PyTorch index is deliberate: on Linux, plain
# `torch==2.13.0` from PyPI is the CUDA build (~2 GB of wheels for GPU support
# that no free host provides). The +cpu local version exists only on the
# PyTorch index, so this forces the small CPU build on any Python 3.11-3.13.
#
# scikit-learn/SciPy are NOT here on purpose - they are only needed to compute
# evaluation metrics, not to serve a prediction. See requirements-dev.txt.
